# ☕ Coffee Orders Dashboard — Excel

An interactive **Coffee Orders Analysis Dashboard** built in Microsoft Excel to analyze sales, customers, products, and order performance.

## 📊 Project Overview

This project focuses on transforming raw coffee order data into an interactive dashboard using Excel's data analysis and visualization features.

The dataset is organized into three interconnected sheets:

* **Orders** – Contains order-level transaction details.
* **Customers** – Contains customer information.
* **Products** – Contains product details such as category and pricing.

The sheets were connected using Excel lookup functions, allowing information from different tables to be combined for analysis.

## 🛠️ Excel Skills Used

* Excel Formulas

## 📈 Dashboard

The interactive dashboard includes multiple charts and visualizations to explore:

* Sales performance
* Order trends
* Product performance
* Customer analysis
* Category-wise insights
* Time-based sales trends

**Interactive features:**

* Slicers for filtering the dashboard
* Timeline for date-based analysis
